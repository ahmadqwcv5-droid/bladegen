# حزمة L1A-01

أرسل هذه الحزمة كاملة إلى الـAgent الذي يعمل في المستودع الحالي.

- `L1A_01_REPOSITORY_CLEANUP_AND_BLADE_BASELINE.md`: البرومت التنفيذي.
- `reference_user_x57/`: نسخ مطابقة بالبايت لملفات تجربتك الشخصية الناجحة، لتثبيت مرجع إعادة الاختبار.
- `SHA256SUMS.txt`: بصمات الملفات، لا يتضمن ملف البصمات نفسه.

هذه الحزمة تعليمات ومرجع بيانات؛ لم تنفذ تنظيفاً للمستودع أو توليد CAD جديداً. لا تحتوي STEP الخاص بمهمتك. على الـAgent البحث عنه في مجلد المهمة المسجلة، إن لزمت المقارنة المباشرة.

فك الحزمة في مجلد واردات جديد دون الكتابة فوق ملفات المشروع. من مجلد الحزمة المفكوك يمكن التحقق باستخدام:

```bash
sha256sum -c SHA256SUMS.txt
```

الهدف تثبيت الجزء الخاص بالريشة، وليس إعلان اكتمال المستوى الأول أو قبولك الشخصي لتجميع المروحة.
